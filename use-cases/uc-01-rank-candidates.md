# UC-01 — Ранжирование резюме кандидатов

**Проект:** информационная система автоматизированного ранжирования кандидатов  
**Основа:** лабораторная работа № 3 по системному анализу  
**Статус:** проектный сценарий; реализация и тестирование не подтверждены

## Назначение

HR-специалист запускает оценку резюме по критериям выбранной вакансии и получает упорядоченный список кандидатов.

## Участники

- **Основной участник:** HR-специалист.
- **Система:** обрабатывает резюме, рассчитывает рейтинг и сохраняет результаты.

## Предусловия

- HR-специалист авторизован.
- В системе есть активная вакансия с критериями оценки.
- Резюме для вакансии загружены и доступны для анализа.
- Администратор настроил алгоритм ранжирования и веса критериев.

## Событие запуска

HR-специалист выбирает вакансию и нажимает кнопку **«Запустить ранжирование»**.

## Основной сценарий

1. HR-специалист открывает вакансию и выбирает функцию ранжирования.
2. Система получает список резюме, относящихся к вакансии.
3. Система извлекает текст и структурирует сведения из резюме.
4. Для каждого кандидата система оценивает данные по заданным критериям: опыт, навыки, образование и другие профессиональные параметры.
5. Система вычисляет итоговый рейтинг с учётом весовых коэффициентов.
6. Система сортирует кандидатов в порядке убывания рейтинга.
7. Результаты сохраняются в базе данных.
8. HR-специалист просматривает список и при необходимости открывает карточку кандидата.

## Альтернативные ситуации

**А1. Неподдерживаемый формат резюме (шаг 3)**  
Система помечает резюме как **«ошибка анализа»** и сообщает об этом HR-специалисту.

**А2. Не хватает части сведений о кандидате (шаг 4)**  
Система отмечает резюме как **«неполное»**. В исходной учебной работе предложено снижать вес отсутствующих критериев; точный порядок пересчёта требует уточнения.

**А3. Одинаковые рейтинги нескольких кандидатов (шаг 5)**  
В исходной работе предложено использовать дополнительный критерий, например стаж или профильность опыта. Правило выбора и порядок приоритетов нужно формализовать отдельно.

## Результат

Сформирован, сохранён и показан HR-специалисту ранжированный список кандидатов по вакансии.
