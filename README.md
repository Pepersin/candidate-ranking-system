# Candidate Ranking System

**Учебный проект информационной системы автоматизированного ранжирования кандидатов**

## О проекте

Проект посвящён анализу и проектированию информационной системы для автоматизации предварительного отбора кандидатов на вакансии.

Основная цель — сократить трудозатраты HR-специалистов при сравнении кандидатов и формировании рейтинга по заданным критериям.

## Предусмотренные функции

- Ведение информации о кандидатах.
- Настройка критериев оценки.
- Ранжирование кандидатов на основании выбранных критериев.
- Просмотр результатов оценки.
- Формирование отчётов.
